# Setting Up GitHub Pages

## Introduction
GitHub Pages is a powerful feature that allows you to host static websites directly from a GitHub repository. Whether you're creating a personal portfolio, documentation site, or project showcase, GitHub Pages makes it simple to get started.

## Steps to Set Up GitHub Pages

### 1. Create a Repository
First, create a new repository on GitHub. If you’re setting up a personal site, name it `<your-github-username>.github.io`.

### 2. Enable GitHub Pages
- Go to your repository settings.
- Scroll down to the "Pages" section.
- Under "Source," select a branch (typically `main` or `docs`).
- Click "Save" and wait for the deployment.

### 3. Add an `index.md` or `index.html` File
Your site needs a main landing page. Add an `index.md` for Markdown-based content or `index.html` for custom HTML.

### 4. Customize Your Site
- Use a theme from [GitHub Pages Themes](https://pages.github.com/themes/).
- Modify the `_config.yml` file for additional settings.

### 5. Commit and Push Changes
Once your files are ready, commit and push them to GitHub. Your site will be available at `https://<your-github-username>.github.io`.

## Conclusion
GitHub Pages simplifies website hosting without requiring a separate web server. Whether you're a beginner or an experienced developer, it’s an excellent tool for sharing projects effortlessly.

Happy coding!
